## Inline Visuals 0.3.0

**13 种图型，样式可调，Agent 可以改图。**

```text
plugin_manager({ action: "install_bundle", target: "@oi-yao/dsh-inline-visuals" })
```

### 新增

- **2 种新图型**：
  - `waterfall`：浮动条形瀑布图，适合收入/成本/利润桥、增减分解；
  - `heatmap`：矩阵热力图（行 × 列），颜色强度由主题色派生，适合请求分布/时段密度。
- **`style` 样式块**（数据不变，只改呈现）：
  - `orientation: horizontal` 横向条形；
  - `stacked` 堆叠（bar/line/area）；
  - `curve: linear | smooth | step` 阶梯线；
  - `points` 数据点、`values` 数值标签、`legend` 图例、`grid` 网格；
  - `palette: default | mono | cool | warm | success`；
  - `height` 160–420、`density: compact | normal`；
  - `trendLine`：散点线性拟合。
- **`edit_visual` 工具**：Agent 可以基于上一张图做局部修改——只传要改的字段，
  对象合并、数组替换、`null` 删除。它从会话日志读上一张图的 spec，不重发数据、不重调模型。

### 示例

```text
你：把三种缓存方案的命中率画成柱状图，加一句结论。
你：把这张图改成横向、堆叠，并打开数值标签。
```

第二句会触发 `edit_visual({ patch: { style: { orientation: "horizontal", stacked: true, values: true } } })`。

### 变更

- 规格版本升到 `3`；渲染器仍接受 v1/v2，历史会话继续可重放。
- 测试从 12 个增加到 26 个。

### 已知边界

- 卡片视觉需在浏览器人工确认（浅色/深色、中英文案）；
- `edit_visual` 默认改「本会话最近一张图」，跨会话不支持。
