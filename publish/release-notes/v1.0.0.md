## Inline Visuals 1.0.0

**14 种图型 · 样式可调 · 可点选追问 · Agent 可改图。首个稳定版本。**

```text
plugin_manager({ action: "install_bundle", target: "@oi-yao/dsh-inline-visuals" })
```

### 1.0 新增

- **`flow` 图型**：分层 DAG，带标签的边；归一化阶段拒绝环和未知节点引用。共 **14 种**图型。
- **点选追问**：点击图表数据点 → 显示选中值 + 「追问这点」按钮 → 自动把结构化追问插入输入框，
  不需要手打上下文。
- **复制 CSV**（所有表格类图型）与 **导出 SVG**（自绘卡片：heatmap / flow / gantt）。
- **Reduce motion**：`prefers-reduced-motion` 下关闭图表动画。
- 无障碍：canvas/SVG 的 ARIA 标签、SVG 元素 `title`、原生表格语义。

### 修复

- `ChartCanvas` 现在以包含 `style` 的完整 spec 作为 key：`edit_visual` 只改样式时也会重绘
  （此前样式补丁会被已有图表忽略）。

### 稳定性承诺

- 公开契约：spec `version: 3`；`show_visual` / `edit_visual` / `style` 词表由 32 个测试覆盖；
- 旧 spec（v1/v2）继续可渲染，历史会话不受升级影响；
- 破坏性改动只在大版本发生。

### 验证

- `npm test`：32/32 通过
- `npm publish --dry-run`：待发布（等 NPM_TOKEN 更新后由 tag 触发）
- live 安装：`Tool.listTools` 同时包含 `show_visual`（14 kind + style）与 `edit_visual`

### 已知边界

- 点选追问目前只覆盖 Chart.js 图型；SVG 类卡片后续补上；
- 浏览器内视觉需人工确认；
- 挂起式输入组件（选择结果回传模型）仍在 v1.2 路线图。
