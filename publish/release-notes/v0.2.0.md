## Inline Visuals 0.2.0

**11 种图型，可重放，一行安装。**

```text
plugin_manager({ action: "install_bundle", target: "@oi-yao/dsh-inline-visuals" })
```

### 新增

- **7 种 Chart.js 图表**：`bar`、`line`、`area`、`pie`、`doughnut`、`scatter`、`radar`
  （主题色、tooltip、图例、动画、PNG 导出）
- **4 种自绘结构化卡片**：`compare` 对比表、`timeline`、`gantt`、`metrics` KPI 卡片
- **文本回退**：TUI、导出、日志里会收到紧凑的文字摘要（列表或 Markdown 表）
- **PNG 导出**（Chart.js 图型）与「复制数据 / 查看数据」
- **工程化**：`src/` 源码 + esbuild 构建、`node:test` 测试、GitHub Actions CI、
  产物漂移校验、npm provenance 发布流水线

### 变更

- 包名：`@community/dsh-inline-visuals` → **`@oi-yao/dsh-inline-visuals`**
- 规格版本升到 `2`；渲染器仍接受 `version: 1`，历史会话继续可重放

### 验证

- `npm test` 12/12 通过（归一化 / 文本回退 / Chart.js 配置 / 客户端 bundle 冒烟）
- `npm publish --dry-run`：85.6 kB，10 个文件，public
- 真实安装验证：`install_bundle` → `applied`，`show_visual({kind:"pie"})` 返回 v0.2 文本回退

### 已知边界

- 卡片视觉需要在浏览器里人工确认（浅色/深色、中英文案）
- 输入型交互（卡片内选择回传模型）在 v1.0 路线图
