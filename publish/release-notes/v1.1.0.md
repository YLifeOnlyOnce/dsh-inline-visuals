## Inline Visuals 1.1.0

**18 种图型，新增机器学习与论文阅读专用图。**

```text
plugin_manager({ action: "install_bundle", target: "dsh-inline-visuals" })
```

### 新增图型

- **`curve`**：ROC / PR / calibration 曲线，支持 AUC 与 y=x 对角线；
- **`histogram`**：分布直方图（自动分箱，默认 10 bins）；
- **`confusion`**：混淆矩阵（行=真实类别，对角线高亮，自动算 accuracy / recall）；
- **`leaderboard`**：模型对比排行榜（每个指标按 `better: up/down` 高亮最佳）。

### 新增能力

- **log 轴**：`style.xScale / yScale: "log"`，训练曲线与 scaling law 直接可画；
- **EMA 平滑**：`style.smoothing: 0–0.9`，对噪声曲线做呈现层平滑；
- **误差棒**：`series[].errors` + `style.errorBars: true`，画 ± 误差；
- **分组散点**：`scatter.data.series: [{ name, points }]`，适合 t-SNE / UMAP 的类别聚类；
- **ROC 对角线**：`style.baseline: true`。

### 修复

- 注册 `LogarithmicScale` 并把轴类型从 `"log"` 修正为 Chart.js 的 `"logarithmic"`
  （此前 log 轴会在浏览器里报 `"log" is not a registered scale`）。

### 验证

- `npm test`：38/38 通过（新增 curve/confusion/histogram/leaderboard、log 轴、平滑、误差棒、分组散点测试）
- `docs/ml-gallery.png` 用真实 Chart.js 配置渲染 6 张 ML 卡片（训练曲线、ROC、embedding、直方图、混淆矩阵、排行榜）
- live 安装：`dsh-inline-visuals@1.1.0`，`show_visual({kind:"curve"})` 与 `{kind:"leaderboard"}` 均返回正确的文本回退
- 浏览器内视觉需人工确认

### 已知边界

- 平滑只影响呈现，文本回退/CSV 仍用原始数据；
- log 轴在数据存在非正值时自动回退线性。
