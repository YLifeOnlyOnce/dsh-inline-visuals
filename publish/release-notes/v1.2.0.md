## Inline Visuals 1.2.0

**结构化内容也能画：看板、桑基图、层级树。**

```text
plugin_manager({ action: "install_bundle", target: "dsh-inline-visuals" })
```

### 新增图型（共 21 种）

- **`kanban`**：状态看板。列 + 卡片，支持 `detail`、`tags`、`tone`（default/success/warn/error），
  适合任务流、发布计划、评审状态。
- **`sankey`**：桑基图。节点 + 带权重的流向（DAG 校验、value > 0），适合预算去向、服务依赖、
  流量分配；自绘 SVG，不额外引入插件。
- **`tree`**：层级树。目录、组织架构、分类体系；tidy 布局 + 直角连接线，深度 ≤ 6。

### 展示

- 三种卡片同样支持「工具卡片」与「正文下方」（turn tail）两处渲染；
- 支持文本回退与 CSV 导出；
- 布局算法是纯函数（`src/client/layout.js`），有独立测试。
